# 赛盟微商城需求规划

## 1. 业务定位

赛盟微商城是一个面向进口商品流通场景的共享分销平台，连接平台运营方、入驻分销商、终端客户与未来的进口商供应侧，通过商城交易能力承载商品分销，通过 AI 提升营销效率、客户运营效率与经营分析能力。

## 2. 角色定义

补充原则：

- 同一账号允许同时拥有客户角色与分销角色。
- 角色是权限叠加关系，不是身份切换关系。
- 分销商一定先是实名认证客户，再升级获得分销权限。

### 2.1 平台运营方

负责：

- 平台商品总库管理
- 分销商入驻审核与资料管理
- 平台会员管理
- 订单、售后、营销活动管理
- 进口资质与风控审核
- AI 配置、内容审核、知识库维护

### 2.2 分销商

负责：

- 入驻申请
- 店铺信息维护
- 选择可分销商品
- 生成分销链接
- 上传自有商品
- 管理自己的分销商品、订单、客户与营销动作
- 查看报价、利润测算、营销内容建议

### 2.3 终端客户 / 小店 / 小批发商

负责：

- 注册与实名认证
- 浏览商品
- 下单采购
- 接收营销内容
- 咨询售后与商品问题

### 2.4 平台会员

面向商城消费者或采购客户，具备账号、地址、订单、售后、收藏、浏览记录等能力。

### 2.5 复合角色用户

部分用户既是客户也是分销商：

- 先完成实名认证，获得客户能力。
- 再完成分销商认证，增加分销能力。
- 仍保留购买、下单、售后等客户侧权限。

## 3. 业务模块拆分

## 3.0 核心业务规则

1. 平台运营可直接创建商品并上架。
2. 分销商入驻后，可从平台公海库选品加入自己的分销库。
3. 分销商可上传自有商品，但必须经过赛盟运营审核。
4. 审核通过后的分销商自有商品进入公海库，供其他分销商继续选择分销。
5. 分销商品是“商品归属 / 来源”与“分销关系”分离，不允许为每个分销商复制一份商品主数据。

## 3.1 商城交易域

### 首期必须

- 首页、分类、搜索、商品详情
- 购物车、结算、订单提交
- 订单支付状态流转
- 订单列表、订单详情、售后申请
- 收货地址、发票信息占位

### 二期扩展

- 优惠券、满减、组合购
- 多仓库存
- 预售 / 拼团 / 秒杀

## 3.2 商品中心

### 首期必须

- 平台商品总库
- 公海共享商品池
- 商品 SPU / SKU
- 品牌、分类、产地、规格、保质期、资质信息
- 商品来源标记：平台自营上传 / 分销商上传
- 商品上下架
- 商品审核状态
- 分销商可分销范围配置
- 分销商选品入库
- 分销链接生成
- 商品素材管理

### AI 一期

- 商品卖点智能提炼
- 图文营销素材生成
- 多渠道文案生成：朋友圈、短视频、小红书、私域文案
- 互补商品推荐占位

### 后续

- 竞品价格监控
- 海关备案数据抓取
- 原产地 / 营养成分自动抽取

## 3.3 分销商中心

### 首期必须

- 入驻申请
- 审核流程
- 实名认证后升级分销角色
- 店铺资料
- 结算信息
- 资质上传
- 分销商品管理
- 公海库选品
- 自有商品提报
- 分销订单查看
- 客户列表

### AI 一期

- 客户分层标签占位
- 话术生成
- 补货预测占位
- 报价单生成占位
- 利润测算

### 后续

- 渠道返利规则
- 裂变邀约
- 自动对账

## 3.4 平台运营中心

### 首期必须

- 仪表盘
- 分销商审核
- 实名认证信息查看
- 商品审核 / 管理
- 公海库管理
- 会员管理
- 订单管理
- 售后管理
- 资质审核
- AI 内容审核
- 角色权限

### 后续

- 经营分析
- 舱位预测
- 拼柜方案
- 物流联动

## 3.5 AI 营销中心

将需求方提供的 AI 能力按落地难度分三层：

### A 类：首期可做，依赖内部数据

- 商品卖点智能生成
- 多场景营销文案生成
- 私聊跟进话术生成
- 售后问答机器人基础版
- 订单搭配推荐基础版
- 利润测算
- 活动方案文案生成

### B 类：二期可做，需要规则与更多数据

- 客户分层画像
- 需求智能预判
- 阶梯报价智能核算
- 月度对账单生成
- 渠道裂变返利核算

### C 类：三期可做，需要外部系统打通

- 库存与效期智能预警
- 销量预测规划舱位
- 拼柜智能匹配
- 竞品价格监控
- 资质真伪智能核验

## 4. MVP 边界

MVP 目标不是一次性做完全部 AI 商流闭环，而是先完成：

1. 平台可管理商品、分销商、会员、订单。
2. 分销商可入驻、选品、上传自有商品、分销、查看订单。
3. WEB 端可完成商城下单闭环。
4. AI 能输出“可用内容”，先做内容生成与辅助决策，不做高依赖自动执行。
5. 风控先做“资料收集 + 人工审核 + 预警”，不做真伪自动判定。
6. 用户角色支持“客户 + 分销商”叠加。

## 8. 验收标准

### 首期验收

1. 三端可独立启动。
2. 后端可正常构建运行。
3. 分销商入驻审核链路可走通。
4. 商品从平台上传或分销商提报到审核入库再到商城展示可走通。
5. 下单链路可走通。
6. AI 营销模块至少可生成商品卖点与营销文案。
7. 运营后台可管理商品、分销商、会员、订单。
